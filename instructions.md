# Конвертер фотографий для Wanwukeyin

Этот инструмент специально создан для решения проблемы с загрузкой фотографий (особенно с iPhone / HEIC) на китайский сайт `h5.wanwukeyin.com`.

## Что делает скрипт:
1. **Преобразует HEIC в обычный JPG**.
2. **Уменьшает размер**, если фото слишком большое (до 3000 пикселей).
3. **Ограничивает вес файла** до 2.5 МБ.
4. **Очищает все скрытые метаданные** (EXIF, ICC цветовые профили), из-за которых сайт часто не может определить размер фото и выдает ошибку.
5. **Нумерует фото** по порядку (1.jpg, 2.jpg...).

## Как пользоваться:

1. Откройте папку `input` и положите туда все фотографии, которые нужно конвертировать. 
   *(Поддерживаются форматы: .jpg, .heic, .png и другие)*
2. Дважды кликните по файлу **`run.command`**.
   *(При первом запуске он может скачивать нужные пакеты, поэтому подождите немного)*
3. Дождитесь появления надписи "Готово!" в черном окне терминала.
4. Откройте папку `output` — там будут лежать уже готовые фотографии, идеальные для загрузки на сайт.

> **Важно**: При каждом новом запуске старые файлы в папке `output` удаляются автоматически, чтобы не было путаницы. Всегда забирайте готовые фото перед следующей конвертацией.
